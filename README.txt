STUDENT MANAGEMENT FRONTEND

1. Extract the ZIP file.
2. Open the students-ui folder.
3. Double-click index.html, or open it with VS Code and use Live Server.

FEATURES
- Add, view, edit and delete student records (client-side CRUD).
- Form validation and duplicate roll-number checking.
- Search by name, roll number or email.
- Filter by department, semester and status.
- Sort by name, roll number, semester or newest.
- Record count cards.
- Import and export JSON.
- Pagination (5 records per page).
- Audit log of the last 10 changes.
- localStorage persistence.

IMPORTANT
Data is saved only in the current browser on this device. It is not connected to a server or shared between devices.
Imported JSON should be an array of objects with: name, rollNo, email, department, semester.
